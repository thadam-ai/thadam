## Refresh the captures

From the repository root, create a fresh workspace:

```shell
python -m examples.dashboard_demo --output artifacts/thadam-showcase
python -m examples.generation_demo \
  --output artifacts/thadam-showcase/scenario-suggestions
thadam dashboard artifacts/thadam-showcase
```

Use a new output folder if it already exists; both demos preserve existing data.
No model API key or subscription is required.

1. Set the browser viewport to 1440 × 960 and use the dashboard's default dark theme.
2. Open **Evaluations → candidate.json**, with `changed-boundary` and its failed
   `decision` check expanded. Capture `evaluation.jpg`.
3. Switch to the light theme and open **Suites → cases.json**. Select
   `within-policy` in Form view. Capture `suite-editor.jpg`.
4. Restore dark mode and open **Comparisons → comparison.json**, with the
   `changed-boundary` regression expanded. Capture `comparison.jpg`.
5. Open **Suites → scenario-suggestions/suggestions.json**, with the first pending
   case selected. Capture `scenario-review.jpg` without accepting or saving cases.

Wait for fonts, data, and the viewport resize to finish before each capture. Keep
the complete application frame visible. Capture the real UI without compositing
or invented values. Retain truthful unavailable states and controlled-demo labels.
Keep credentials, authorization URLs, private paths, tooltips, and browser chrome
out of the image. Restore temporary viewport/theme settings afterward.

When the visible interface changes, refresh the affected images and update the
capture commit/date here. Check the [dashboard tour](../../dashboard-tour.md) and
[repository README](../../../README.md) for legibility and working relative paths.
